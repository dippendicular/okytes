# Community conduct

Treat contributors and users with respect. Critique the work, explain your
reasoning, and give people room to ask questions and correct mistakes.
Harassment, discriminatory language, threats, sexual attention, publication of
private information, and repeated personal attacks are not welcome.

This applies to repository discussions, issues, pull requests and other project
spaces. Maintainers may remove harmful content, restrict participation, or ban
accounts. Decisions should be proportionate, protect affected people, and be
explained where doing so does not disclose private information.

Report conduct concerns privately to the repository owner through their GitHub
profile. Do not post another person's private information in an issue. If no
private contact route is available, request a private contact channel without
including sensitive details. No dedicated incident-response team is promised.
